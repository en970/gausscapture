# Export Formats

- `raw_export.zip`: model file and `metadata.json`.
- `web_export.zip`: static web viewer bundle with `index.html`, model, metadata, and README.
- `blender_export.zip`: model plus Blender import notes.
- `unity_export.zip`: `UnityAssets/Models`, a loader placeholder, and integration notes.
- `proxy_mesh_export.zip`: experimental `proxy_mesh.obj` when Open3D reconstruction succeeds, plus a report JSON.
